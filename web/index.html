Buddy

Buddy can edit files and run commands on the machine it is running on, so it asks for a code. It is printed in the terminal that started it, and this device will remember it. After ten wrong tries you will have to wait a little before trying again.

Just talk, like a call. Say a project's name to put it on the line (“Ada, run the tests”), or status for a roll call. Only the project on the line speaks; the others report through Buddy. Say allow Ada to grant a permission, park Ada to put one away. Also: pause, go on, stop, stop everyone, repeat, shorter, go to sleep. Keys 1–9 switch projects.
