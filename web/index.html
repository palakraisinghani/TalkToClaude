Install Claude Code

In a terminal on that computer:

curl -fsSL https://claude.ai/install.sh | bash

Or with npm: npm install -g @anthropic-ai/claude-code. Then restart ClaudeCall so it finds it.

Sign in

On the computer running ClaudeCall, open a terminal and run:

claude auth login
or use an API key

A key is kept on that computer only, readable by you alone, and used by your agents. Get a key

Behind the scenes

Seat a new agent

    Hands-free: a soft blip means a try was kept, a low tone means say it again. Say skip, done or stop any time.

    Rename

    One word, easy to say, and not like anyone else's name. Next you will say it a few times so ClaudeCall learns your voice.
