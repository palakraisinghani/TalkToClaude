ClaudeCall

Lead your Claude team by voice

Talk to Ada, your assistant. She sets up projects, hands out the work and tells you who needs you, while each Claude Code agent works away in its own folder on your computer.

You'll need Claude Code, signed in.

Every agent is a Claude Code session, so it runs on your Claude subscription (Pro or Max) or Console account. No API key needed. Not installed yet? ClaudeCall walks you through it when you open it, or in a terminal:

curl -fsSL https://claude.ai/install.sh | bash
claude auth login
1. InstallMac: open the .dmg and drag ClaudeCall to Applications. Ubuntu/Debian: sudo apt install ./ClaudeCall-linux-x64.deb
2. Open ClaudeCallIt opens in its own window and runs in the background, so your team keeps working when you close it.
3. Press call and talk"Ada, start a project for a recipe website. Call the agent Kiwi." Say a name to talk to that agent.
