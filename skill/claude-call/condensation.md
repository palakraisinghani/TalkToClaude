# Condensation patterns

- **List of seven**: "Three are worth doing, four more if you want them." Name the three, count the rest.
- **Diff**: Say how many files and what area they cover, never the paths. "Five files, mostly the login flow and its tests."
- **Stack trace**: Say the cause in plain words. "A null check is missing in the token refresh."
- **Table**: Turn it into a comparison sentence. "Option A is cheapest, option B is fastest, option C is a middle road."
- **Long explanation**: One sentence verdict, up to three supporting points, then "want me to go deeper?"
- **Code**: Describe what it does, put the snippet on screen in visual mode, offer to save it in audio-only mode.
